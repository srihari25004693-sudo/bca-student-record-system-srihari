STUDENT RECORD SYSTEM
BCA 2nd Year Mini Project

A simple console-based Python project to manage student details,
using SQLite for storage.

FEATURES
- Add a student
- View all students
- Search a student by roll number
- Update a student's record
- Delete a student

REQUIREMENTS
- Python 3.8 or higher
- No extra packages needed

INSTALL
pip install bca-student-record-system-srihari

RUN
student-records

Records are saved in a file called students.db in the folder
where you run the program.
